# B8A1: TypeScript Assignment

## Overview

This assignment covers TypeScript fundamentals and object-oriented programming. The `solutions.ts` file contains eight problems on functions, type narrowing, readonly tuples, generics, interfaces, classes, and asynchronous validation.

It also includes two blog posts on TypeScript concepts:

- [Type Aliases vs. Interfaces](./type-alias-vs-interface.md)
- [Type Narrowing](./type-narrowing.md)
